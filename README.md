#Image Search Engine

Overview

This is a simple Image Search Engine built using HTML, CSS, and JavaScript. It allows users to search for images by typing a keyword, and it fetches images from the Unsplash API. Users can also load more images by clicking the "Show More" button.

#Features

Search for images using keywords

Display images in a grid layout

Load more images using the "Show More" button

Responsive design for better user experience

#Technologies Used

HTML

CSS

JavaScript

Unsplash API

#How to Use

Clone the repository:

git clone https://github.com/sithumimadhushika/image-search-engine.git

Navigate to the project directory:

cd image-search-engine

Open index.html in your browser.

Type a keyword in the search box and press "Search".

Click on the displayed images to view them on Unsplash.

Click "Show More" to load additional images.

API Key Configuration
